精确路由证据

路由证据 / V2

看见响应报告的路由。

Route Inspector 对照 ChatGPT 的请求模型与响应路由字段。它不问模型“你是谁”，不凭速度猜测，也不保存你的聊天正文。

安装前已经打开的 ChatGPT 页面需要刷新一次，扩展才能开始捕获。

01 / LIVE

捕获新请求

切到“实时请求”并发送消息，同时读取 requested 与本轮 response route。

02 / RELOAD

复查已有回答

切到“会话重载”并刷新目标会话；优先读取会话响应路由，尚未捕获时以 DOM 标签兜底。

03 / EXACT

显示精确字段

实际路由字段决定 route，模型标签只作补充；不使用百分比。

04 / PRIVACY

白名单字段，本地留存

正文、Cookie、Authorization、JWT 和附件不会写入扩展存储。
