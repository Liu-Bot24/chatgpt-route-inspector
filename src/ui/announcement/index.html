版本公告

  1. 根据此前投票反馈，响应结果中存在 resolved_model_slug 字段的用户约 80% 未降级；没有该字段的用户约 80% 发生了降级。

    故针对响应结果中 resolved_model_slug 字段缺失的情况，新增“疑似降级”标记提醒。*

  2. 本扩展的正确应用范围是网页版 Chat 模式。网页版 Work 模式的降级情况与 Codex 一致，请按照 Codex 排查。

* 单纯图片生成任务响应结果中不带 resolved_model_slug 字段属正常现象，请自行辨别。

历代更新日志

  1. v1.0.9

    修复新建会话时实时请求模型与响应路由无法显示的问题；扩展连接失效时提示刷新页面，避免浮窗按钮无响应。

  2. v1.0.8

    新增“疑似降级”标记。

  3. v1.0.7

    实时请求与会话重载同时独立采集，切换标签即可查看；优化浮窗排版。

  4. v1.0.6

    适配增量流、多行 SSE 与 WebSocket；修复请求配对与记录隔离；新增额度快照和 5.6/5.5 自动推理状态。

  5. v1.0.5

    修复 ChatGPT 页面重建后浮窗消失的问题，并保留手动隐藏设置。

  6. v1.0.4

    适配 ChatGPT 官方后端会话接口的路径与响应结构调整。

  7. v1.0.3

    新增迷你浮窗与边缘停靠，优化英文文案和窄屏排版。

  8. v1.0.2

    支持项目内会话的重载路由识别，并加强导出脱敏与隐私测试。

  9. v1.0.1
